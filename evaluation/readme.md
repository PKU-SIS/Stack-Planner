# Reference


## 实验 Pipeline

本数据集围绕以下 4 步生成流程设计：

1. **Step1：基于检索文档生成文档片段（含引用）**
2. **Step2：对文档片段进行二次加工（增加约束）**
3. **Step3：将多个片段拼接成连贯文档**
4. **Step4：对连贯文档进行风格改写（如鲁迅风格）**

## 数据集设计

本数据集用于测试 **文档生成中的引用模块（Reference Module）**，重点评估：

1. **引用生成准确率**
2. **引用迁移能力**
   * Step1 → Step2 是否保持引用标记
   * Step1 → Step3（拼接阶段）是否保持引用标记
3. **文档拼接后的流畅性** #需要自己跑出来结果，不提供label
4. **风格迁移后引用是否丢失** #需要自己合并，不提供label


### 数据集结构设计

⚠ 所有字段均为 **string**
⚠ 单层结构
⚠ 不使用嵌套 JSON

每一条样本包含以下字段：



#### 基础信息

| 字段名            | 说明                   |
| -------------- | -------------------- |
| id             | 样本唯一编号               |
| user_query     | 用户原始问题               |
| outline        | 生成文档的大纲              |
| node_id        | 当前节点 ID              |
| parent_node_id | 父节点 ID（根节点可为 "None"） |


### 检索与支撑

| 字段名             | 说明                |
| --------------- | ----------------- |
| support_docs    | 支撑文档内容（可拼接成一个字符串） |



### Step1（生成片段）

| 字段名                  | 说明                  |
| -------------------- | ------------------- |
| step1_input          | Step1 输入内容          |
| step1_output         | Step1 输出文档片段（含引用，基线） |



### Step2（二次加工）

| 字段名                         | 说明                                |
| --------------------------- | --------------------------------- |
| step2_input                 | Step2 输入 |
| step2_output                | Step2 输出文档片段                      |


---

### Step3（拼接阶段）

| 字段名                         | 说明         |
| --------------------------- | ---------- |
| step3_input                 | 多个片段拼接前的输入 |
| step3_output                | 拼接后的完整文档   |


---

### Step4（风格改写）

| 字段名                         | 说明             |
| --------------------------- | -------------- |
| step4_style                 | 目标风格（如 "鲁迅风格"） |
| step4_output                | 风格化后的文档        |

### 示例样本（单条示例）

```text
id: R001
user_query: 人工智能在医疗中的应用有哪些？
outline: 1. 辅助诊断 2. 药物研发 3. 医疗影像分析
node_id: N1
parent_node_id: None
support_docs: D1: 人工智能可以辅助医生进行疾病诊断... D2: AI在药物筛选中加速了新药研发...

step1_input: 基于支撑文档生成关于辅助诊断的段落
step1_output: 人工智能可以辅助医生进行疾病诊断【1】。

step2_input: 在原段落基础上增加技术细节说明
step2_output: 人工智能通过深度学习模型辅助医生进行疾病诊断【1】。

step3_input: 段落1 + 段落2
step3_output: 人工智能通过深度学习模型辅助医生进行疾病诊断【1】。同时也加速了药物筛选【2】。

step4_style: 鲁迅风格
step4_output: 所谓智能，不过是机器替人分忧罢了，它竟也能替医生诊断疾病【1】。
```



## 测试目标

### 1 引用生成准确率

检测 Step1 生成的引用是否：

* 正确对应支撑文档
* 标记格式正确
* 没有 hallucination 引用
* 参考 Deep Research Bench 的 Fact 指标的引用准确率
```
引用准确率 = 正确引用数量 / 生成引用数量
```
---

### 2 引用迁移测试

检测：

* Step2 是否保留 Step1 的引用标志
* Step3 拼接后是否仍保留引用
* Step4 风格改写后引用是否丢失

标准：

* 简单标准，{1,3,2}=={1,2,3}用于风格覆盖
* 严格标准，{1,3,2}=={1,3,2}!={1,2,3}用于文档拼接 

指标：
```
保留率 = 保留下来的引用数量 / 应保留引用数量
```
